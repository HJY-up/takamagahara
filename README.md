# 高天原 · 绘梨衣的东京赛博箱庭

单文件前端应用：把番茄钟、便利贴、待办与草莓牛奶装进东京夜色里的治愈系专注箱庭。

## 功能

- 番茄钟 / 休息自动切换、专注轮次与连续记录
- 便利贴、待办清单
- 小游戏与解锁、金币等成长系统
- 可选 AI 对话（默认关闭，需在设置里自行填写 Base URL / API Key / 模型）

## 使用

直接用浏览器打开 `index.html`，无需构建、无外部依赖（资源全部内联）。

本地起个静态服务也可以：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 数据与隐私

- 全部数据存放在浏览器 `localStorage`，清除站点数据会一并清空，不上传任何服务器。
- 开启 AI 后，内容会直连你在设置里填写的接口地址；密钥同样只存在本地。
